## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщика по умолчанию".
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован.
    * Windows 11 позволяет включить Secure DNS в настройках самой ОС - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут быть нарушены.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/holddirectorpraise/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, скачанных и открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Извлеките файлы в путь без кириллицы и специальных символов.

5. Запустите нужный скрипт.
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автоматический запуск, выберите **`service.bat`** -> `Install Service` -> подходящую стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии.

  Такой запуск подходит для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящий вариант**.

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - включить или выключить обход для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  После изменения параметра стратегию необходимо перезапустить.  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - изменить режим обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Это удобно при проверке ресурса, который без zapret работает нормально.  
  В скобках показывается текущий режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP проверяется по списку
    - `any` - фильтр применяется к любому IP  
  - **`Auto-Update Check`** - включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить выбранный активный fake на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; иногда это возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** - запустить проверку стратегий:
    - `Standard tests` - проверка сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если он не запустился, обратитесь к [#522](https://github.com/holddirectorpraise/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - С помощью текстового редактора, запущенного от имени администратора, откройте файл `hosts` в созданной папке.
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленный аналогичный фрагмент.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если этот способ не сработал, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/holddirectorpraise/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Работа стратегии не гарантируется бессрочно.**
> Вариант, который какое-то время помогал, может перестать работать после его обнаружения.
> В репозитории собрано много стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках.

- Проверьте наличие нужного адреса в списках доменов или IP.

- Протестируйте другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/holddirectorpraise/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Запустите `service.bat` -> `Remove Services`.
- Выполните `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/holddirectorpraise/zapret-discord-youtube/releases), файл вида `zapret-discord-youtube-...`.
- Откройте свойства архива правой кнопкой мыши. Если внизу есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы.
- Запускайте разные `general`-скрипты и проверяйте доступ к нужным ресурсам. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию.
- После выбора рабочей стратегии включите её автозапуск через `service.bat` -> `Install Service`.

### Не работает игра/приложение с включённым запретом

- Проверьте в `service.bat`, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе обход может повлиять на неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. В командной строке Windows, открытой через Win+R и `cmd`, определите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- См. также [#251](https://github.com/holddirectorpraise/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте работу приложения после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузерная версия также недоступна, повторно протестируйте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/holddirectorpraise/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/holddirectorpraise/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно помогает следующая последовательность:
- в `service.bat` обновите ipset и включите `Game Filter`;
- если этого недостаточно, дополнительно включите режим `ipset any`.

Учтите: `ipset any` может нарушить открытие большого числа сайтов. Не оставляйте его включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/holddirectorpraise/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/holddirectorpraise/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`.
