> ### Реакция антивирусов
> WinDivert иногда распознаётся антивирусом.  
> Это средство перехвата и фильтрации сетевого трафика, необходимое для работы zapret.
> Один и тот же инструмент могут применять как легитимные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов относит WinDivert к потенциально опасным классам или хакерским инструментам, после чего удаляет файл и отправляет его в карантин. Название детекта обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо выключите проверку PUA (потенциально нежелательных приложений). Например, Kaspersky содержит настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений лучше добавить исключение; если назначение параметров непонятно, рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Сначала включите Secure DNS.
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`. Cloudflare может оказаться заблокирован.
    * Windows 11 позволяет включить Secure DNS в настройках самой операционной системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/holddirectorpraise/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите нужный сценарий.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> нужную стратегию.

## ℹ️ Файлы и их возможности

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **проверяйте разные варианты, включая ALT, FAKE и другие, пока не найдёте подходящий**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** устанавливает выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** переключает обход для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние указывается в скобках: включено или выключено.
  - **`IPSet Filter`** управляет обходом сервисов из `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним нет.  
  Статусы означают:
    - `none` - проверка не применяется ни к одному IP;
    - `loaded` - IP сверяется со списком;
    - `any` - под фильтр попадает любой IP.  
  - **`Auto-Update Check`** включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** заменяет используемый fake на другой файл из `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для исправления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность.
  - **`Run Tests`** проверяет стратегии:
    - `Standard tests` тестирует сайты из `utils/targets.txt`;
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/holddirectorpraise/zapret-discord-youtube/issues/522).

### Не нашлась подходящая стратегия

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не подключается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое открывшегося блокнота.
  - От имени администратора откройте текстовым редактором файл `hosts` в созданном каталоге.
  - Вставьте скопированный текст в конец файла `hosts` или замените ранее добавленный аналогичный фрагмент.
  - Сохраните файл и снова проверьте подключение. Если результата нет, проверьте, действительно ли файл сохранился.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/holddirectorpraise/tg-ws-proxy) или публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение стратегии может привести к тому, что ранее рабочий вариант перестанет помогать.
> В репозитории собрано много стратегий. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте ошибки через `service.bat` -> `Run Diagnostics`.
- Убедитесь, что нужный адрес присутствует в списках доменов или IP.
- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/holddirectorpraise/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- В `service.bat` выберите `Remove Services`.
- В `service.bat` запустите `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите старый каталог zapret.
- Скачайте свежий архив (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/holddirectorpraise/zapret-discord-youtube/releases).
- Откройте свойства архива правой кнопкой мыши. Если внизу есть пункт разблокировки, нажмите его, затем `Применить` и `ОК`.
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте доступность ресурсов. Если интернет не работает, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- После выбора рабочего варианта включите автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` - **`none`**. Иначе обход может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Используйте инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть в службах

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- См. [#251](https://github.com/holddirectorpraise/zapret-discord-youtube/discussions/251).

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте работу приложения Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если веб-версия тоже не работает, снова проверьте стратегии: YouTube и Discord могут работать на разных вариантах.
- См. [#252](https://github.com/holddirectorpraise/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/holddirectorpraise/tg-ws-proxy).
- Либо используйте бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

У `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/holddirectorpraise/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

- Создайте обращение [здесь](https://github.com/holddirectorpraise/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые следует исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
